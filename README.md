설화 속 도깨비 현상을 과학으로 규명하며 지점을 이동하는 미스터리 추적 체험.

## 배포 (GitHub Pages)

빌드 과정·외부 의존성 없는 정적 사이트입니다.

1. 이 저장소를 GitHub에 푸시
2. Settings → Pages → Source: `main`(또는 배포 브랜치) / root
3. `.nojekyll`이 있어 Jekyll 처리 없이 파일이 그대로 서빙됩니다
4. 발급된 `https://<owner>.github.io/<repo>/` 접속

로컬 확인: `python3 -m http.server 8000` 후 `http://localhost:8000`

### QR / 웨이포인트 방식 (중요)

물리적 QR마다 URL을 심어 페이지를 이어붙이지 **않습니다**. 대신:

- **시작 QR 1개**(프롤로그 입구): 앱을 최초 로드하는 URL. 이것만 URL.
- **각 지점 QR**: `NSM-01` … `NSM-04`(+클라이맥스 `NSM-05`) 형태의 **순수 식별 토큰**.
  앱이 켜진 상태에서 내장 카메라 스캐너로 토큰을 읽어 해당 지점을 매칭합니다.
- 장점: 앱이 한 번 켜진 채 이어져 **오디오·연출이 끊기지 않고**, 링크 공유로 건너뛰는 부정행위를 막고, 인쇄물이 깔끔합니다.
- 선형 가드: 아직 못 푼 앞 지점의 토큰이 아니면 도깨비 목소리로 되돌립니다.

## 콘텐츠 수정

이야기를 고칠 땐 콘텐츠 데이터만 건드리면 되고 렌더 코드는 손대지 않습니다.
(향후 이 스키마에 맞춰 출력하는 저작도구를 붙일 수 있도록 설계)
