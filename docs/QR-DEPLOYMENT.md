# QR 현장 배치 가이드

「기묘한 국중곽 : 21세기 도깨비」 웨이포인트 QR의 종류·의미·배치·재생성 방법.

## QR은 두 종류

| 종류 | 담는 내용 | 스캔 주체 | 목적 |
|---|---|---|---|
| **시작 QR** (`qr/START.svg`) | 배포 **URL** | 관람객 **폰 기본 카메라** | 앱을 최초로 로드 |
| **지점 QR** (`qr/NSM-0X.svg`) | 순수 **식별 토큰**(예: `NSM-03`) | **앱 내장 스캐너** | 해당 지점 조화를 열기 |

> 핵심: 지점 QR에는 URL을 넣지 않는다. 앱이 한 번 켜진 채 이어져야 오디오·연출이
> 끊기지 않기 때문. 앱이 내장 카메라로 토큰을 읽어 지점을 매칭한다.
> (카메라를 못 쓰는 관람객은 앱 화면에서 `NSM-03`을 직접 입력해도 된다.)

## 토큰 ↔ 지점 매핑

| 토큰 | 지점 | 설화 모티프 → 과학 |
|---|---|---|
| `NSM-01` | 제보 01 | 도깨비불 → 가스 자연발화 |
| `NSM-02` | 제보 02 | 부르는 소리 → 초저주파 |
| `NSM-03` | 제보 03 | 홀림(맴돌기) → 방향감각 상실 |
| `NSM-04` | 제보 04 | 밤의 형체 → 음성 잔상·파레이돌리아 |
| `NSM-05` | 클라이맥스 | 팬 홀로그램 도깨비불 → 잔상 합성 |

**진행은 선형 강제**입니다. 관람객이 순서를 건너뛰어 `NSM-03`을 먼저 스캔해도
앱이 "아직 풀지 못한 조화가 남았다"며 막고 현재 지점으로 되돌립니다. 따라서 물리적
배치 순서가 어긋나도 앱이 순서를 보장하지만, **동선은 01→05 순으로 배치**하는 것을 권장합니다.

## 배치

1. **시작 QR**: 프롤로그 입구(광장 체험존 안내). "여기서 시작 — QR을 비추세요" 안내와 함께.
2. **지점 QR** `NSM-01`~`NSM-04`: 각 제보 지점의 표식/전시물 옆.
3. **`NSM-05`**: 팬 홀로그램(클라이맥스) 연출 지점.

### 인쇄 사양
- **SVG 사용 권장**(무손실·확대 자유). PNG(720px)는 미리보기·간이 인쇄용.
- 최소 크기 **한 변 4cm 이상**(야간·거리 스캔 여유를 위해 5~8cm 권장).
- 오차 정정 레벨 **H**(약 30% 손상까지 복원) — 야외 훼손·조명 변화에 강함.
- 충분한 여백(quiet zone) 유지, 저조도 대비 위해 밝은 바탕에 인쇄.

## 재생성

토큰 문구를 바꾸거나 배포 URL이 정해지면 다시 생성합니다. 토큰 목록은
`src/content.js`에서 자동으로 읽으므로 콘텐츠와 항상 동기화됩니다.

```bash
# 기본(예시 URL)
node tools/generate-qr.mjs

# 실제 배포 URL 지정 (시작 QR에 반영)
node tools/generate-qr.mjs --url https://<owner>.github.io/<repo>/
```

출력: `qr/NSM-01…05.{svg,png}`, `qr/START.{svg,png}`

> ⚠️ **시작 QR의 URL은 실제 배포 주소로 재생성**하세요. 저장소/사용자명이 다르면
> 기본값(`https://elderlord.github.io/WayPointGuidance/`)과 달라집니다.

## 검증

생성된 QR이 올바른 토큰으로 디코드되는지 자동 검증됩니다(인쇄→스캔→앱 체인):

```bash
npm test    # qr.test.mjs 가 qr/*.png 를 실제 디코더로 읽어 지점 매핑 확인
```
